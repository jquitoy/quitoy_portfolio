# Joshua Quitoy Portfolio

Modern portfolio website inspired by bryllim.com design.

## Files

- `portfolio.html` - Main HTML file
- `portfolio.css` - Stylesheet with grid layout
- `portfolio.js` - Interactive JavaScript features

## Features

- 6-column responsive grid layout
- Profile header with inline action buttons
- Card-based sections
- Tech stack with tags
- Projects and certifications lists
- Recommendations section
- Gallery grid
- Mobile responsive

## How to Use

1. Open `portfolio.html` in your browser
2. Customize the content with your information
3. Replace placeholder images with your own
4. Update links and social media URLs

## Layout Structure

**Desktop (768px+):**
- Profile header: Full width
- Main content: 4 columns (left)
- Sidebar: 2 columns (right)
- Some sections span 2 columns for variety

**Mobile:**
- Single column stack layout
